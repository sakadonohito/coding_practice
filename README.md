# Coding Practice Logs

日々のコーディング演習、関数型プログラミングや多様なプログラミング言語の学習・アウトプットを記録しているリポジトリです。

## 🎯 目的
- 各種プログラミング言語（特に関数型言語やモダン言語）の仕様・文法・表現力の習得
- 日々の継続的な問題演習とアルゴリズム/設計パターンのキャッチアップ
- 型安全性やコードの可読性を意識した実装トレーニング

## 🛠 取り組んでいる言語・技術スタック
- **Haskell** (Functor, Monad, 型システム, Hspec による TDD)
- **Rust** (所有権, 型システム, エラーハンドリング)
- **Go** (シンプル設計, インターフェース)
- **TypeScript** (型定義, モダンJavaScript)
- **Clojure / F# / Erlang** (関数型パラダイム)
- **Kotlin / Swift / Python**

## 📁 ディレクトリ構造
各言語ごとに、実施日（YYMMDD形式）および課題内容ごとのディレクトリを作成して管理しています。

```text
coding_practice/
├── haskell/
│   ├── 260726/
│   │   └── discountoptionalproduct/  # 各日付ごとの演習コード & テスト
│   └── ...
├── rust/
├── golang/
├── typescript/
└── ...
```

## 🧪 テスト・品質への取り組み
コードを書くだけでなく、単体テスト（Haskell の `Hspec` や Rust/Go/TS の標準・各種テストフレームワーク）を作成して仕様を満たしているかを検証しながら進めています。

```bash
# 例: Haskell のテスト実行
cd haskell/260726/discountoptionalproduct
stack test
```
